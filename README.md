# Mohammad Rayyan — Personal Portfolio

Live site: [https://rayyan-error.github.io/](https://rayyan-error.github.io/)

A fast, recruiter-friendly personal portfolio designed for reading in under 60 seconds.

## Built With
- Semantic HTML5, Vanilla CSS3 (custom tokens, warm paper + caramel palette, auto dark mode + toggle)
- Vanilla JavaScript (active section spy, nav state, dark mode preference persistence)
- Self-contained printable resume generated via headless Chromium (`resume.pdf`)
- Fully responsive across mobile, tablet, and desktop viewports

## Local Preview
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080` in your browser.
