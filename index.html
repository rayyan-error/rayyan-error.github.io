Caramel

Nov 2026 – Present

Offline voice-controlled desktop agent for Linux

A local voice assistant built for speed and predictability. It runs fully offline with no cloud APIs: speech is detected with Silero VAD, transcribed with Vosk, and matched to commands through a deterministic prefix-tree engine that launches apps and runs web searches.

  • 3-state engine (dormant → listening → executing) running as a systemd user service with a global caramel CLI
  • One-command installer that automatically finds the apps installed on the user's machine
  • 8 automated test suites covering audio, recognition, matching, and the CLI
  • Python
  • Vosk / Kaldi
  • Silero VAD (ONNX)
  • Bash
  • systemd
